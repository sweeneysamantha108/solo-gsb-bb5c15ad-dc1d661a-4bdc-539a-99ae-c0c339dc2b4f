# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围、列出全部可行角度段，并默认选择距禁用边界最远、角度最小的旋转量。Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 设备档位约束

在参数面板勾选「启用设备档位约束」（单规格与多规格共用此设置，可分别填写 **每圈档位数 2～360 的整数** 与 **零位偏移 (°)**）：

- 系统只允许角度 `θ = 偏移 + n × 360°/档位数`（按整圈归一到 0°–360°），偏移超出范围自动按整圈归一。
- 档位与当前**可行段**（单规格）或**共用段**（多规格）求交（边界档位也算可用），默认档位沿用 **「瓶颈间隙最大、角度较小优先」** 规则；右栏列出**全部可用档位**及间隙（单规格为该档到最近禁用边界的角距离；多规格逐规格列出间隙与瓶颈档）。
- **连续区间有解但没有可用档位**时，与「保护区覆盖整圈」明确区分：结果区给出琥珀色提示，按每条可行/共用段列出**距该段最近的前、后档位**及角距离；Canvas 环外灰色短刻度为全部档位，琥珀色菱形为最近档位。
- Canvas 拖动**只吸附到可用档位**（圆周距离最近，并列取较小角度），点击可行段则选中该段内的默认可用档位；没有可用档位时位置线变琥珀色且不移动。
- **关闭约束后行为与此前完全一致**；勾选状态、档位数与偏移在单/多规格模式切换、计算与载入快照时都**保留在表单中**，不会因切换模式丢失。

## 多规格共用角度模式

顶部切换到「多规格共用角度」后，可输入 **2～8 个筒体周长**，沿用同一接缝安全宽度与同一组毫米制保护区：

- 系统对每个规格分别计算，再把各规格可行段统一到角度域 **0°–360°** 求圆周交集，输出**所有规格均安全的共用角度段**（跨零点自动合并展示）。
- **默认共用角度**：对候选角度 θ 取其在各规格下到禁用边界的圆周角距离的最小值并最大化（即瓶颈间隙最大），平局时取较小角度；右栏列出该角度在每个规格下的实际间隙与对应毫米位置。
- **无共同解**时，按规格输入顺序定位使公共交集**首次归零**的规格，列出该规格及其禁用区间与此前公共段的**冲突区间**，Canvas 上以红虚线标出。
- **最小违约备选**：公共可行段为空时（无共同解），系统进一步给出一个"违约最小"的备选角度——按各规格禁用角度边界切分整圆，角度落在某规格禁用区内时记其**侵入深度**（沿圆周走出该禁用区所需的最小角距离），选取使**所有规格中最大侵入深度最小**的角度；并列时依次比较**总侵入深度**与**较小角度**。结果区显示备选角度、最大/总侵入深度与各规格侵入深度及无解原因，Canvas 以**琥珀色位置线与菱形**标记该角度（仅作参考，不能变为安全角度）。**启用设备档位约束时只在档位角度中求解**，对应档位刻度同样以琥珀色标出。存在共同安全段时不进行该计算，结果与此前完全一致。
- Canvas 由外向内**叠加每个规格的禁用环**（颜色对应规格序号），绿色环为共用安全段；拖动时吸附到最近的共用安全角度。
- 切回「单规格模式」时，单规格的周长与多规格周长列表均保留在页面中，**不会丢失任何已输入内容**。
- 方案快照仅保存单规格结果，多规格模式下快照入口自动禁用。

## 调机旋转路径规划

在右栏「调机旋转路径」面板输入**当前角度 (°)** 与**目标角度 (°)**（按整圈归一，允许任意数值），系统基于当前模式的安全角度段（单规格**可行段** / 多规格**共用段**）规划调机旋转路径：

- **两端安全**：当前角度与目标角度必须各自落在安全角度段内，否则分别指出「起点不在安全角度段内」或「目标不在安全角度段内」。
- **启用设备档位约束时**，两端还须落在**可用档位**上，否则分别指出「起点/目标不在可用档位上」（端点不安全优先于不在档位报告）。
- **只允许沿圆周连续旋转**且全过程处于安全角度：分别评估**顺时针**与**逆时针**两条路径，在可行路径中**选转角较短者，等长取顺时针**；跨 0°、整圈可行、起终点相同（转角 0°，取顺时针）均正确处理。
- **两端各自安全但被禁用段隔开**时报告**不可达**（沿圆周连续旋转无法全程保持安全角度）。
- 页面显示**方向、转角**与两个方向的可行性，Canvas 外侧绘制**紫色路径弧**（● 当前角度，○ 目标角度，终点带方向箭头；不可达时仅显示红色端点）；参数重算后路径结果**同步刷新**，未手动改过输入时自动以当前位置与默认角度填充。

## 方案快照

- 在「方案快照」面板可为**当前周长、接缝宽度、保护区与设备档位设置的计算结果**命名并保存；快照按时间倒序列出，支持载入参数（含档位开关、档位数与偏移）与删除。
- 勾选两个快照（依次标记为 A、B）后点击比较：系统将三类圆周区间（保护区、合并禁用段、可行段）统一归一化到 **0°–360°**，即使两个快照周长不同也可比较。
- 差异输出：
  - **新增**（B 有 A 无，绿色）／**移除**（A 有 B 无，红色）的圆周区间；
  - **边界移动**（紫色）：按重叠最大配对对应段，给出起点/终点沿最短圆弧的有向位移（顺时针 +、逆时针 −），跨零点自动取短弧；
  - 共有的部分以灰色底环显示。
- 差异 Canvas 上三个环分别对应可行段（外）、禁用段（中）、保护区（内），右栏列出逐段明细（角度，并附各快照周长下的毫米参考值）。
- 快照数据保存在浏览器 **localStorage**（键 `seam-avoidance:snapshots:v1`，最多 100 个），不经过服务器；清除浏览器数据即删除。重新计算或「返回实时预览」即回到原有实时预览。

## 启动（Docker）

前置条件：已安装 Docker 与 Docker Compose（Docker Desktop 自带 `docker compose` 插件）。

单条命令构建并启动（依赖安装与初始化均已纳入镜像构建，启动即就绪）：

```bash
docker compose up --build
```

```bash
# 后台运行
docker compose up --build -d

# 查看日志 / 停止
docker compose logs -f
docker compose down
```

首次启动会执行 `npm ci --omit=dev` 安装依赖并纳入镜像；修改 `server.js`、`src/` 或 `public/` 后需重新 `docker compose up --build`。镜像基于 `node:20-alpine`，容器内以 `node server.js` 运行，不包含开发依赖与单元测试（测试见下方本地开发）。

## 访问

- **网页**：http://localhost:3000
- **API**（与网页同端口 `3000`）：
  - `POST http://localhost:3000/api/compute`（单规格计算）
  - `POST http://localhost:3000/api/compute-multi`（多规格共用角度）
  - `GET  http://localhost:3000/api/health`（健康检查）

## API

| 方法 & 路径 | 说明 |
| ----------- | ---- |
| `POST /api/compute` | 单规格计算。请求体：`{circumference, seamWidth, zones:[{start,end}], detents?, route?}`（单位 mm；`route` 见下） |
| `POST /api/compute-multi` | 多规格共用角度。请求体：`{circumferences:[…2～8 个周长…], seamWidth, zones, detents?, route?}`；返回每个规格的完整单规格结果（`specs[].result`）、圆周交集 `common`（角度弧段）、默认角度 `best.deg` 及各规格间隙 `best.gaps`；无共同解时 `noSolution=true` 并给出 `blocker`（首次归零的规格序号、此前公共段 `priorCommon`、该规格禁用段 `blockingForbidden` 与冲突区间 `conflictSegments`）与最小违约备选 `fallback`（见下） |
| `GET /api/health` | 健康检查 |

`detents`（可选）为设备档位约束：`{enabled:true, steps:2～360 的整数, offsetDeg?:数值角度}`；缺省或 `enabled:false` 时行为不变（返回 `detents:{enabled:false}`）。启用后返回：

- `detents.steps / offsetDeg / stepDeg / positions`：档位参数与全部档位角度；
- `detents.available`：全部可用档位。单规格每项 `{index, deg, mm, gapDeg}`；多规格每项 `{index, deg, minGapDeg, gaps:[各规格间隙]}`；
- 单规格 `best` 取最优可用档位（附 `detentIndex`）；多规格 `best` 同理；
- 连续区间有解但无可用档位时 `best=null`、`detents.noAvailable=true`，`detents.nearest[]` 按可行/共用弧给出 `{before, after}`（最近前、后档位及角距离）；保护区覆盖整圈时 `noSolution=true`、`noAvailable=false`。

### 调机旋转路径 `route`（`POST /api/compute` 与 `POST /api/compute-multi` 共用）

请求体中传入可选的 `route:{fromDeg, toDeg}`（角度，按整圈归一）后，响应中返回结构一致的 `route` 结果；未传时 `route=null`。路径基于单规格可行段 / 多规格共用段计算，启用档位时两端还须落在可用档位上。字段：

| 字段 | 说明 |
| ---- | ---- |
| `fromDeg` / `toDeg` | 归一化到 `[0,360)` 的当前/目标角度 |
| `reachable` | 是否可达（两端安全且存在全程安全的连续旋转路径） |
| `status` | `ok` 可达；`fromUnsafe` / `toUnsafe` 起点/目标不在安全角度段内；`fromNotOnDetent` / `toNotOnDetent` 起点/目标不在可用档位上（启用档位时）；`unreachable` 两端各自安全但被禁用段隔开 |
| `direction` | 选中的方向：`cw` 顺时针 / `ccw` 逆时针；不可达为 `null` |
| `angleDeg` | 选中的转角（°，`0 ≤ angleDeg < 360`；起终点相同为 0，取顺时针）；不可达为 `null` |
| `cw` / `ccw` | 两个方向各自的 `{angleDeg, feasible}`：顺时针/逆时针转角及该方向是否全程安全 |
| `message` | 中文说明（不可达原因或旋转方案） |

选择规则：在可行方向中取**转角较短者，等长取顺时针**；跨 0°、整圈可行、起终点相同均正确处理。

### 最小违约备选 `fallback`（仅 `POST /api/compute-multi`）

公共可行段为空（`noSolution=true`）时返回；有共同安全段时为 `null`。字段：

| 字段 | 说明 |
| ---- | ---- |
| `deg` | 备选角度（°）：使各规格**最大侵入深度最小**，并列比**总侵入深度**，再并列取**较小角度** |
| `maxIntrusionDeg` | 该角度下各规格侵入深度的最大值（°），为 0 表示存在不侵入任何规格禁用区的角度（公共段仅在零宽边界点相接） |
| `totalIntrusionDeg` | 各规格侵入深度之和（°），最大深度并列时的比较依据 |
| `intrusions[]` | 逐规格明细 `{index, circumference, intrusionDeg, mm}`；`intrusionDeg=0` 表示该规格在此角度安全，整圈禁用的规格恒为 180° |
| `detentIndex` | 启用档位约束时备选角度对应的档位序号（0 起）；未启用为 `null` |
| `positions` | 启用档位约束时参与求解的全部档位角度；未启用为 `null`（求解域仅限档位角度） |
| `reason` | 无解原因说明文本（含首次归零规格、是否整圈禁用、求解域是否限定在档位） |

侵入深度定义：角度 θ 落在某规格禁用弧内时，沿圆周走到该弧最近出口的角距离；落在安全处为 0。
